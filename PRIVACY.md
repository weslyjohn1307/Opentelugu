# Privacy Policy & Zero-Telemetry Guarantee

Last updated: October 2026

**OpenTelugu is built on a non-negotiable core principle: complete user privacy and zero data collection.**

---

## 1. Zero Network Egress & 100% Offline Architecture

- **No Network Requests:** OpenTelugu does not make outbound internet connections. It operates 100% offline.
- **No Cloud Servers:** There are no backend databases, APIs, remote analytics servers, or telemetry endpoints associated with OpenTelugu.
- **No Account Required:** You do not need to register, provide an email address, or create an account to download, install, or use OpenTelugu.

---

## 2. Text, Clipboard & OCR Data Processing

- **Local Memory Processing:** Any Telugu text you type, paste, convert, or extract using the offline OCR engine is processed solely in your computer's local volatile memory (RAM).
- **No Logging to Disk:** OpenTelugu does not write your converted documents, scanned images, or typed keystrokes to disk or external storage.
- **Clipboard Management:** When you copy text, it is written exclusively to the local Windows operating system clipboard (`CF_TEXT` and `CF_UNICODETEXT`).

---

## 3. Compliance with Privacy Regulations

Because OpenTelugu does not collect, process, transmit, store, or sell any personal data:
- **Digital Personal Data Protection Act (DPDP Act 2023, India):** Full compliance by design. No personal data processing occurs.
- **General Data Protection Regulation (GDPR, EU):** No personal data is gathered, meeting the principle of data minimization (Article 5(1)(c)).
- **California Consumer Privacy Act (CCPA / CPRA):** No personal information is collected or sold.

---

## 4. Verification

Because OpenTelugu is open source under the MIT License, you can independently inspect the entire codebase, monitor process network activity using tools like Wireshark or Windows Resource Monitor, and compile the application directly from source.
